### 2. Prerequisites Checklist

1. **Visual Studio Code** installed.
2. **Node.js** (v18+ or v20+) installed.
3. **MySQL Service** (WampServer, XAMPP, or native MySQL 8/9) running on port `3306`.
4. Ensure the database credentials in [.env](file:///c:/AuraSupply/.env) match your MySQL settings:
   ```env
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=43200111
   DB_NAME=aura_v1_db
   PORT=3000
   ```
   *(If your MySQL `root` has no password, change `DB_PASSWORD=` to empty).*

### 3. Step-by-Step Instructions to Run in VS Code

#### Step 1: Open the Project in VS Code
1. Open VS Code.
2. Click **File** $\rightarrow$ **Open Folder...** (or press `Ctrl + K, Ctrl + O`).
3. Select `C:\AuraSupply` and click **Select Folder**.

---

#### Step 2: Choose Your Run Mode

You can run the system using either **Method A (All-in-One Full Stack)** or **Method B (Full Dev Mode with Hot-Reload)**.

---

#### Method A: All-in-One Full Stack (Simplest & Recommended)
In this mode, the Express backend serves both the API endpoints **and** the compiled React frontend directly on `http://localhost:3000`.

1. Open the integrated terminal in VS Code:
   * Press ``Ctrl + ` `` (or **Terminal** $\rightarrow$ **New Terminal**).
2. Ensure you are in the root directory `C:\AuraSupply`.
3. If you haven't built the frontend yet, build it once:
   ```powershell
   cd AuraTheme
   npm run build
   cd ..
   ```
4. Start the server:
   ```powershell
   node server.js
   ```
5. You will see:
   ```text
   🚀 Aura Global Server running at http://0.0.0.0:3000
   🌐 Default Website:  http://0.0.0.0:3000/
   🛍️ E-Menu WebApp:    http://0.0.0.0:3000/shop/sbc-store
   📡 E-Menu & TMA API: http://0.0.0.0:3000/api/tma/stores
   [Database] Connected successfully to MySQL (127.0.0.1:3306/aura_v1_db)
   ```

---

#### Method B: Full Development Mode (with Live Hot-Reload for React)
Use this mode if you are making active code edits to React components in `AuraTheme/src/` and want instantaneous hot-module replacement (HMR).

1. **Terminal 1 (Backend API)**:
   * Open integrated terminal in `C:\AuraSupply`:
     ```powershell
     node server.js
     ```
   * *The backend API runs on `http://localhost:3000`.*

2. **Terminal 2 (Frontend Dev Server)**:
   * Click the **+** (Split or New Terminal) icon in VS Code.
   * Switch into the `AuraTheme` directory:
     ```powershell
     cd AuraTheme
     npm run dev
     ```
   * *The Vite dev server runs on `http://localhost:5173` and automatically proxies all `/api` requests to port `3000`.*

---

### 4. VS Code One-Click Shortcuts

Pre-configured VS Code tasks and debug profiles are now available in your workspace:

* **F5 Debugger**:
  * Press **`F5`** anywhere in VS Code to launch `server.js` with the Node.js debugger attached.
* **Run Tasks**:
  * Press `Ctrl + Shift + P` $\rightarrow$ type **`Tasks: Run Task`** $\rightarrow$ Select:
    * `1. Start Backend Server (Port 3000)`
    * `2. Start Frontend Dev (Vite Port 5173)`
    * `3. Build Frontend Production (AuraTheme/dist)`
